| ** 解释覆盖 ** | `full` | 能解释全部已知现象  | **+0.05** | 
| | `partial` | 只能解释部分现象  | **-0.05** | 
| | `has_exceptions` | 有⽆法解释的观测事实  | **-0.10** | 
| ** 节俭性 ** | `minimal_assumptions` | 前提假设最少、最⾃然  | **+0.05** | 
| | `needs_new_mechanism` | 需要引⼊新的未知机制  | **-0.05** | 
| | `needs_multiple` | 需要多个额外假设  | **-0.10** | 
| ** 理论兼容 ** | `compatible` | 与主流理论⾃然兼容  | **+0.05** | 
| | `partial` | 部分兼容，存在张⼒  | **-0.05** | 
| | `requires_revision` | 要求修改 / 推翻已有理论  | **-0.10** | 
| ** 可证伪性 ** | `current_data_testable` | 可操作且当前数据可检验  | **+0.10** | 
| | `needs_new_data` | 需要新数据 / 新实验  | **-0.05** | 
| | `not_testable` | ⽆明确证伪条件  | **-0.10** | 
| | `infeasible` | 当前技术⽔平⽆法实现  | **-0.10** | 
| ** 区分度 ** | `distinct` | 与所有替代假设都不同  | **+0.05** | 
| | `partial_overlap` | 与部分假设预测重叠  | **-0.05** | 
| | `high_overlap` | 与所有假设⾼度重叠  | **-0.10** |

科学质询者识别不确定性时，需满⾜以下四个条件：
