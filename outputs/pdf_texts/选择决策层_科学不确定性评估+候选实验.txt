2.4评估逻辑（程序实现）
代码块
def prioritize_uncertainties(uncertainties, hypothesis_tree, 
experiment_memory): 
    for u in uncertainties: 
        # 计算涉及假设数量权重 
        hypothesis_count = len(u.related_hypotheses) 
        # 计算假设⽀持度差距权重 
        supports = [hypothesis_tree.get(h).support_score for h in 
u.related_hypotheses] 
        support_gap = max(supports) - min(supports) 
        # 计算预期信息增益（基于假设预测差异） 
        expected_ig = calculate_expected_information_gain(u, hypothesis_tree) 
        # 计算成本 
        estimated_cost = estimate_experiment_cost(u) 
        # 综合优先级评分（⼈类 PI 可⼿动调整权重，或加⼊特殊情况调整） 
        priority_score = ( 
            0.35 * hypothesis_count / 3 +   # 涉及假设越多越重要 
            0.25 * (1 - support_gap) +       # ⽀持度越接近越需要区分 
            0.25 * expected_ig +             # 信息增益越⾼越重要 
            0.15 * (1 - estimated_cost)      # 成本越低越优先 
        ) 
        u.priority_score = priority_score 
    return sorted(uncertainties, key=lambda u: u.priority_score, reverse=True)

2.1模块定位与职责
位置：实验规划者内部的核⼼⼦模块，在“科学不确定性评估”之后、“实验决策引擎”之前。
职责：
1. 从当前假设树和不确定性队列中，⽣成⼀组候选实验（候选池）
2. 为每个候选实验标注：检验哪个假设、区分哪对假设、实验设计（变量/滞后/控制）、预期结果
3. 确保候选实验之间有⾜够的区分度（不是重复或近似重复）
4. 输出给决策引擎进⾏综合价值评估和选择
