## 〇、全局制作规范

1. **画面规格**：1920×1080 / 30fps；录屏统一 100% 缩放、隐藏书签栏与通知、深色主题前端；旁白录音在剪辑最后一步对齐。
2. **五层进度条**：片头生成一张五层架构图（人工控制层 / 推理规划层 / 知识记忆层 / 选择决策层 / 执行评价层 / 数据程序层），从 S4 起常驻右下角，每幕高亮当前层（半透明底 + 描边发光）。
3. **段落字幕卡**：每幕转场用 1.5 秒全屏黑底白字一句话（见各幕【转场卡】），保证静音可看懂骨架。
4. **数字原则**：本脚本中所有指标数值（r=0.41→0.51、U=0.73、支持度 0.45→0.62 等）均为设计文档示例值，**正式录制前必须用真实跑出的结果替换旁白与字幕中的数字**，逐镜表中标注 ⚠️ 的即需回填。
5. **真实性原则**：所有系统画面必须来自真实录屏（前端、终端、日志、JSON）；仅"假设树生长动画""公式演算动画"两处允许后期动画，且动画内容须与真实 JSON 数据一致。
6. **时间水印**：所有加速/跳剪的执行画面左上角加"REC 03:12→04:35 ×8速"式水印，保住"可复现"信任分。
